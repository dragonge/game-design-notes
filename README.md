## 💡 使用指南

1. **添加新的灵感**：
   - 复制 `templates/inspiration-template.md` 到 `docs/` 目录下；
   - 按照 `YYYY-MM-DD-主题.md` 命名，记录对标游戏、核心闭环与实施路线；
   - 更新本 `README.md` 中的文档索引。

2. **定位与原则**：
   - **重在落地与精炼**：拒绝假大空的设计，立足独立团队的开发边界。
   - **对标经典但做差异化**：分析成功作品“为什么好玩”，并提取最契合项目调性的核心机制。
