## 💡 使用指南

1. **添加新的灵感**：
   - 在 `docs/` 下创建当日的日期目录：`docs/YYYY-MM-DD/`（如 `docs/2026-11-03/`）；
   - 复制 `templates/inspiration-template.md` 到该目录；
   - 命名为 `YYYY-MM-DD-HHmm-主题.md`（HHmm 为当前时分，如 `1546`）；
   - 记录对标游戏、核心闭环、落地路线，并在顶部的“归档时间”写死精确时间；
   - 更新本 `README.md` 中的索引表。

2. **定位与原则**：
   - **重在落地与精炼**：拒绝假大空的设计，立足独立团队的开发边界。
   - **对标经典但做差异化**：分析成功作品“为什么好玩”，并提取最契合项目调性的核心机制。
