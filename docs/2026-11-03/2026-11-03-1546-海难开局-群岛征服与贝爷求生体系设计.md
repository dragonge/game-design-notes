【开局心流链条】
狂风暴雨船只沉没 ➔ 清晨被浪花拍打在沙滩上苏醒 ➔ 浑身湿透濒临失温 ➔ 
寻找背风巨石搭建简易棕榈叶草棚 ➔ 钻木取火烤干衣服 ➔ 赶海敲牡蛎充饥 ➔

正式开启废弃灯塔与补给站的重建！

### 家园营地建造的【四阶段跃迁】

2. **阶段 2：修缮守林木屋与石磨厨房**（清理藤蔓杂石、开垦规整菜田、解锁烹饪与储物）；
3. **阶段 3：建立补给栈桥与造船台**（修复破损码头，立起风向标，打造单桅帆船，接待外港小船）；
4. **阶段 4：点亮灯塔主透镜与灵兽暖阁**（温室花架、灵兽专属软垫窝、彻夜不灭的金光航标）。

## 三、 宏观格局跃迁：从“立足母岛”到“造船征服外岛群”

游戏不再局限在单一小岛上，而是划分为**前半程立足母港**与**后半程扬帆远征**两大壮阔阶段：

```
【第一阶段：母岛扎根与造船准备（0 ~ 3.5 小时）】
海难荒岛求生 ➔ 建立岩洞火种 ➔ 修缮守林屋 ➔ 结识阿岚与救助首只灵兽海獭“阿水” ➔
阿水接管每日浇地与退潮拾贝（生产力解放） ➔ 修复旧船坞造船台 ➔ 打造第一艘单桅帆船扬帆起航！

【第二阶段：出海开拓三大特色外岛（3.5 ~ 7.5 小时）】
驾驶帆船驶入大洋迷雾，攻克 3 座生态各异的神秘副岛，点亮环岛辅信标网：
```

### 🏝️ 外岛 1：【低潮荧光礁】（极致潮汐解谜）
* **特征**：平时完全沉入水下，**仅在极低潮（大潮汛）的短暂 4 小时内浮出海面**；
* **挑战**：驾船压哨赶到，在礁石迷宫中解开潮汐闸门，抢救林遥留下的防水信筒；
* **收获**：捕获“发光荧光水母”（用于配制超远距离灯塔燃油），采集紫海带与黑海胆。

### 🌲 外岛 2：【古林迷雾岛】（灵兽与稀有木料）
* **特征**：常年被厚重海雾笼罩，罗盘失灵，参天铁杉木遮蔽天空，深处盘踞未知生灵；
* **挑战**：依靠灵兽阿水的嗅觉穿透迷雾，利用安抚料理驯服林中巨兽；
* **收获**：结识第二只灵兽“疾风灵鸮佩佩”（可在桅杆上驱散迷雾并预警暗礁），伐取铁杉木强化帆船撞角与船舱。

### 🌋 外岛 3：【沉船遗迹与锻造岩岛】（金属与重工基地）
* **特征**：黑曜石悬崖，遍布巨型古代货轮残骸，海风狂啸；
* **挑战**：攀爬倾斜锈蚀的船体舱段，修复岛顶被雷击损毁的副信标塔；
* **收获**：搜集齿轮机械、稀有熔炼金属、获取林遥亲手绘制的“大洋全域海图”。

## 四、 终局大高潮（第 7.5 ~ 8 小时）：全域光之航路网

1. **三岛信标与母岛灯塔共鸣**：三大外岛副信标全部点亮，与母岛主灯塔在夜空中交织成金色光芒航道网，大洋浓雾彻底消散；
2. **深海巨兽平息**：航标频率修复，巨兽停止暴动，浮上海面发出温柔长鸣；
3. **外港大商船入港**：林遥乘着首艘客船归来，与阿岚团聚释怀；
4. **从荒滩到奇迹之港**：玩家站在崖顶回望——最初那个冻得发抖、捡树枝生火的孤零零沙滩，如今已成了灯火辉煌、船来船往、人与灵兽欢聚的温暖中转港。
