## 一、开发背景与核心目标

### 1. 核心问题定位
目前游戏虽已走通“种田-烹饪-莫恩任务-浅滩赶海”全流程，但游玩体验易退化为**“为了看剧情而不得不办手续（交任务换材料）”**。玩家缺乏主动探索的内在动机。

### 2. 本次任务交付目标
通过对交互演出、剧情钩子、视听反馈与伙伴机制的手术级打磨，构建**“外出消耗 ➔ 归岛松弛 ➔ 温情款待 ➔ 伙伴回馈 ➔ 引爆下一轮好奇”**的黄金微循环：
1. **归岛迎接感**：从外图回营地触发轻快提示与叶芽团欢快迎接，卸下疲惫；
2. **莫恩款待与沉船传闻（核心探险钩子）**：交付热汤时增加感官化描写，莫恩喝完热汤后**口述透露南湾（Cove）退潮时露出的老沉船残骸**；
3. **叶芽团羁绊赠礼**：每日探险归来抚摸叶芽团，它会从泥土下推给玩家赶海/农田小礼物；
4. **潮汐赶海打捞**：南湾退潮浅滩新增【搁浅货船残骸（`cove_wreck`）】，打捞可得航海记录与关键建材；
5. **退潮广播提醒**：低潮开始时播发广播与音效，制造紧迫的窗口期感。

### 任务 2：扩展状态机 `scripts/state.gd`

#### 2.1 增设变量声明
在 `scripts/state.gd` 变量声明区（约 line 60 附近）新增：
```gdscript
var morn_cove_rumor_unlocked: bool = false
var cove_wreck_looted: bool = false

```

#### 2.2 `reset_run()` 初始化
在 `reset_run()` 内重置这些变量：
```gdscript
morn_cove_rumor_unlocked = false
cove_wreck_looted = false
pet_leaf_daily_gifted_day = 0
```

#### 2.3 新增灵兽互动与回礼方法
```gdscript
func interact_pet_leaf() -> Dictionary:
	var gave_gift := false
	var gift_item := ""
	if pet_leaf_daily_gifted_day != day:
		pet_leaf_daily_gifted_day = day
		gave_gift = true
		var pool := ["shell", "wheat_seed", "turnip_seed"]
		gift_item = pool[randi() % pool.size()]
		give(gift_item, 1)
	return {"gave_gift": gave_gift, "gift_item": gift_item}
```

#### 2.4 升级存档 `save_game()` 与向下兼容 `valid_save()` / `load_game()`
- 在 `save_game()` 的 `data` 字典中存入：
  `"morn_cove_rumor_unlocked": morn_cove_rumor_unlocked, "cove_wreck_looted": cove_wreck_looted, "pet_leaf_daily_gifted_day": pet_leaf_daily_gifted_day`
- 在 `valid_save(data)` 中加入布尔与整型校验：
  ```gdscript
  for key in ["morn_cove_rumor_unlocked", "cove_wreck_looted"]:
      if data.has(key) and not data[key] is bool: return false
  if data.has("pet_leaf_daily_gifted_day") and not is_number(data.pet_leaf_daily_gifted_day): return false
  ```
- 在 `load_game()` 中安全还原：
  ```gdscript
  morn_cove_rumor_unlocked = bool(data.get("morn_cove_rumor_unlocked", false))
  cove_wreck_looted = bool(data.get("cove_wreck_looted", false))
  pet_leaf_daily_gifted_day = int(data.get("pet_leaf_daily_gifted_day", 0))
  ```

### 任务 4：地图实体与潮汐逻辑 `scripts/world.gd`

#### 4.1 归岛迎接判定
在 `load_zone(id, from_zone, restore_position)` 中：
- 若 `id == "home"` 且 `from_zone in ["forest", "cove"]` 且 `state.pet_leaf_rescued`:
  - 触发归岛粒子：`emit_sparks(Vector2(240, 470), Color("88ff88"))`；
  - 播放清脆音效：`sound_requested.emit("farm")`；
  - 弹出消息：`state.say("PET_LEAF_WELCOME_TOAST")`。

#### 4.2 南湾（Cove）退潮沉船生成
在 `load_zone("cove")` 判定为 `low_tide` 时：
- 除了原有 `cove_shell_0`, `cove_shell_1` 外，新增沉船残骸实体：
  ```gdscript
  add_actor("wreck", "cove_wreck", Vector2(650, 480), "COVE_WRECK_NAME", 55)
  ```
- 在 `interact()` 的 `match actor.kind:` 分支中添加 `"wreck"` 处理：
  ```gdscript
  "wreck":
      if not state.cove_wreck_looted:
          state.cove_wreck_looted = true
          state.give("ore", 3)
          state.give("stone", 4)
          state.say("COVE_WRECK_LOOT_SUCCESS")
          sound_requested.emit("repair")
          emit_sparks(actor.pos, Color("f5dca1"))
      else:
          state.say("COVE_WRECK_ALREADY_LOOTED")
  ```

#### 4.3 伴随退潮开始广播
在 `tick()` 中：
- 记录上一帧是否为低潮 `var was_low_tide: bool`；
- 当 `Calendar.is_low_tide(state.clock)` 由 `false` 转为 `true` 时：
  - 播放潮水退去音效 `sound_requested.emit("travel")`；
  - 广播全局消息：`state.say("TIDE_LOW_WARNING_BANNER")`。
